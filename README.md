# 究極の単語帳アプリ (Ultimate Flashcard App)

AIによる学習サポートと、スワイプ操作による直感的なUIを組み合わせた、フルスタック単語帳Webアプリケーションです。

## ✨ 特徴 (Features)

*   **🧠 AI自動生成＆添削 (Powered by Gemini API)**
    *   単語のみを入力するだけで、Gemini APIが自動で意味を生成・登録します。
    *   ユーザーが意味を手入力した場合も、内容をAIがチェックし、間違いがあれば修正案を提示します。
*   **📱 TinderライクなスワイプカードUI**
    *   直感的なタッチ操作（スワイプ）に対応。
    *   右スワイプで「覚えた（⭕️）」、左スワイプで「苦手（❌）」に自動で振り分けます。
*   **⚠️ 苦手克服アルゴリズム**
    *   左スワイプ（苦手）と判定された単語のみを抽出し、集中的に再テストできる復習モードを搭載。
*   **🔊 ネイティブ音声の自動読み上げ**
    *   Web Speech APIを活用し、フォルダーの言語設定（英語/日本語）や出題方向（順引き/逆引き）に合わせて音声を自動再生します。
*   **💾 データ管理とセキュアな設計**
    *   JSON形式での学習データのバックアップ（エクスポート/インポート）に対応。
    *   APIキーをフロントエンドに露出させないため、Vercel Serverless Functions (`api/generate.js`) を用いたバックエンド通信を構築しています。

## 🛠️ 技術スタック (Tech Stack)

*   **Frontend:** HTML5, JavaScript (Vanilla), Tailwind CSS
*   **Backend:** Node.js (Vercel Serverless Functions)
*   **API:** Google Gemini 1.5 Flash API, Web Speech API
*   **Hosting:** Vercel

## 💡 こだわった開発ポイント

単なる「Webサイト」ではなく、「ネイティブアプリのような体験（UX）」を提供することにこだわりました。
PCブラウザ・スマホブラウザの双方に完全対応（レスポンシブ設計）しており、ダークモードへの切り替えも可能です。また、ユーザーが面倒なAPIキーの設定をしなくてもすぐにAI機能を使えるよう、バックエンド（Vercel）を経由してAPIリクエストを行うアーキテクチャを採用しています。
